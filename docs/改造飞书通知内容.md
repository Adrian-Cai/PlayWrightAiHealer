   * Jenkins 报告链接

测试用例调用方式也要改

原来可能是：

await aiAssert(page, 'text=批量确认', '批量确认按钮');

改成：

test('人工确认-批量确认按钮校验', async ({ page }, testInfo) => {
  await page.goto('https://ai-case.wiac.xyz/');

  await aiAssert(
    page,
    'text=批量确认',
    '批量确认按钮',
    testInfo
  );
});

testInfo 很关键。
没有它，飞书通知就不知道是哪条 case 触发的自愈。

核心设计

不要再发这种消息：

AI 自愈测试开始
AI 自愈测试完成
缓存中有 2 条记录

改成：

测试开始：可以只打印到控制台
测试过程：只记录自愈事件
测试结束：飞书发送完整汇总

最终飞书只保留一条高价值消息：

本次测试跑了几个 case
失败了几个 case
哪几个 case 失败
哪个元素失效
原始 locator 是什么
AI 修复 locator 是什么
修复成功还是失败
错误原因是什么
报告地址是什么
